Google Sheets
Apps Script · бесплатно
Все диалоги записываются в Google Таблицу. Нужно один раз задеплоить Apps Script — займёт 3 минуты.
Инструкция:
1. Откройте Google Sheets → Extensions → Apps Script
2. Вставьте код ниже и нажмите Deploy → New deployment → Web App
3. Execute as: Me, Who has access: Anyone → Deploy
4. Скопируйте URL и вставьте ниже
function doPost(e){var d=JSON.parse(e.postData.contents);SpreadsheetApp.getActiveSheet().appendRow([d.timestamp,d.bot,d.user,d.user_message,d.bot_reply,d.channel]);}

Чтобы запустить голосовой бот
Получите бесплатный API Яндекс SpeechKit — и бот начнёт принимать голосовые сообщения в Telegram.
  1. 1Зайдите на console.yandex.cloud → создайте платёжный аккаунт (карта для верификации, не списывается)
  2. 2IAM → Сервисные аккаунты → Создать → добавить роль ai.speechkit.user
  3. 3API-ключи → Создать ключ → скопировать
  4. 4Railway → Variables → добавить YANDEX_API_KEY = ваш_ключ
  5. 5Написать боту голосовое в Telegram — он ответит голосом 🎙️
